Auctions and VCG Explorer

Shoham & Leyton-Brown, Multiagent Systems, ch. 7: Thm 7.9 (second-price), Thm 7.10 (first-price), Fig 7.3 (VCG shortest path). Every curve uses the closed forms from REPORT.md.

Second-price sealed-bid auction

Bidder 1 has value v and bids b. The highest bid wins and pays the highest rival bid. Move the sliders: the peak of the curve stays at b = v whatever the rivals do.

First-price auction, n bidders

Bidders 2…n play the equilibrium bid (n−1)/n·v. Bidder 1 bids k·v₁ with v₁ ~ U[0,1]. The curve is bidder 1's ex-ante expected utility; its peak sits at the equilibrium shading k = (n−1)/n.

VCG for the cheapest A→F path (Fig 7.3)

Each directed edge is an agent with a private cost. Change what an edge declares. VCG picks the path that is cheapest by declared cost and pays each chosen edge (cost of best path without it) − (others' declared cost on the chosen path). Utility always uses the true cost. The last column shows what the edge gains by its declaration versus telling the truth, others as declared: it is never positive.
